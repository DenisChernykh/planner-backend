# Ритм — цели и привычки в ChatGPT

Личный плагин: читать план, создавать и изменять цели, записывать результаты,
прибавлять количество, работать с корзиной и настраивать напоминания.
«Ритм» — название продукта и плагина. `planner` — название репозитория;
MCP — протокол инструментов, а не название продукта.

## Общий интерфейс

UI собирается из `../frontend/src`: те же маршруты, страницы, таблица плана,
инспектор факта, форма цели, корзина, напоминания, компоненты и цвета.
`frontend/src/app/chatgpt/main.tsx` подключает MCP Apps bridge и memory router.
`createChatGptAdapter` переводит вызовы штатного сгенерированного API-клиента
в именованные инструменты. Сессия, ключ и запросы к API остаются на сервере.
Встроенный UI не обращается к API по сети из браузера.

Все CSS, JavaScript и шрифты включены в один HTML-ресурс
`ui://ritm/app-v1.html`. CSP не разрешает внешние подключения или ресурсы.
Поддерживаются inline и fullscreen, светлая и тёмная темы контейнера.
Ключи управляются в веб-версии; в плагине скрыты веб-выход и «Подключения».

При открытой панели видимые данные перечитываются каждые 30 секунд,
при возвращении фокуса и при уведомлении контейнера о результате инструмента.
Обновление по таймеру пропускается при активном вводе или сохранении.
Дату `today` возвращает API, месяц по умолчанию определяется в часовом
поясе аккаунта из настроек напоминаний.

## Подключение личного аккаунта

Новая реализация использует отдельный отзывной ключ вместо cookie браузерной
сессии. Сначала нужно опубликовать API с миграциями `0005` и `0006`; локальная реализация
и тесты сами ничего не публикуют.

1. В веб-версии открыть «Подключения» и нажать «Создать ключ».
2. В приватных runtime-настройках существующего Sites сохранить:
   - `RITM_API_TOKEN` — secret, только что созданный ключ;
   - `RITM_OWNER_EMAIL` — email владельца ChatGPT.
   - `RITM_ACCOUNT_ID` — ID подключаемого аккаунта Ритма из `/api/auth/me`.
3. Опубликовать новую версию существующего Site с доступом **только владельцу**
   и названием **Ритм**. Старый адрес и `project_id` сохранены в hosting.json.
4. Обновить подключённый плагин в ChatGPT и открыть «Ритм».

Ключ показывается один раз, действует год и хранится в D1 только как SHA-256.
Новый ключ заменяет предыдущий; «Отозвать доступ» сразу запрещает дальнейшие
вызовы. Выход из веб-версии не отзывает ключ. Он разрешает `/api/auth/me`, цели,
планы и напоминания и не разрешает управление ключами, входом или заметками.
Старые `PLANNER_SESSION` и `PLANNER_OWNER_EMAIL` новая версия не использует.

Каждое обращение к данным проверяет доверенную identity Sites
`oai-authenticated-user-email` и её совпадение с владельцем, затем ключ через
`/api/auth/me` и совпадение его ID с `RITM_ACCOUNT_ID`. При ошибочной замене
ключа чтение плана и изменения запрещены. Владелец плагина в ChatGPT и владелец
подключённого аккаунта Ритма могут отличаться при согласованном доступе.
Email, ключ и ID подключения не принимаются в аргументах инструментов.
Email и ключ не включаются в UI, результаты или сообщения об ошибках. Это личная интеграция;
публичная публикация с общим ключом не поддерживается.

## Инструменты

Названия ниже — технические ID. В ChatGPT используются русские заголовки.

| ID | Название | Действие |
| --- | --- | --- |
| `open_ritm` | Ритм | Общий UI; текущий либо явно выбранный месяц |
| `get_account` | Мой аккаунт | Проверка подключения |
| `get_plan` | Посмотреть план | Цели и результаты месяца |
| `create_goal` | Добавить цель | Новая цель с `input` и `month` |
| `update_goal` | Изменить цель | Изменение параметров без смены типа учёта |
| `record_entry` | Записать результат | Полный итог дня и необязательная заметка |
| `adjust_entry` | Прибавить к результату | Прибавление к количеству с `operationId` |
| `delete_entry` | Убрать результат | Удаление результата дня |
| `delete_goal` | Перенести цель в корзину | Мягкое удаление |
| `get_trash` | Посмотреть корзину | Удалённые цели месяца |
| `restore_goal` | Восстановить цель | Возвращение в план |
| `reorder_goals` | Изменить порядок целей | Порядок внутри группы |
| `get_reminder_settings` | Посмотреть напоминания | Общие настройки и статус Telegram |
| `save_reminder_settings` | Настроить напоминания | Часовой пояс, тихие часы, вечерний обзор |
| `get_goal_reminders` | Посмотреть расписание целей | Настройки целей месяца |
| `save_goal_reminder` | Настроить напоминание о цели | Время, дни и режим |
| `connect_telegram` | Подключить Telegram | Одноразовая ссылка; пользователь подтверждает её в боте |
| `disconnect_telegram` | Отключить Telegram | Отзыв связи с чатом |

Создание и редактирование передают тело API в `input`; `record_entry` — в
`entry`. Месяц `YYYY-MM`, дата `YYYY-MM-DD`, время `HH:mm`, ID целей — UUID.
Все четыре типа учёта и все три периода совпадают с веб-версией.

«За день 200 мл» записывает итог `200`. «Ещё 200 мл» прибавляет к существующему
количеству, начиная с нуля, если записи нет. Для новой операции передаётся UUID
`operationId`; повтор с тем же UUID не прибавляет ещё раз. При одновременном
изменении запись не затирается, возвращается `409 ENTRY_CONFLICT`.
Заметка сохраняется. Подтверждение прибавления хранится до удаления самой цели
из D1, включая время в корзине; плановая очистка старых напоминаний его не удаляет.
Прибавление доступно только для количества.

Инструкции сервера требуют сначала прочитать план, уточнять неоднозначные
цели/значения, учитывать единицы и даты аккаунта, не повторять создание после
потери ответа и перечитывать данные после изменений.

## Локальная разработка и проверка

Node 24 и pnpm 11.15.1, установка **из корня** workspace:

```sh
pnpm install --frozen-lockfile
pnpm check
pnpm chatgpt:build
pnpm chatgpt:dev
```

Для личного локального обращения ключ и email задаются только в игнорируемом
`chatgpt/.env` по `.env.example`. Endpoint `http://127.0.0.1:8790/mcp`, только
loopback. Dev-сервер имитирует проверенную identity владельца Sites.

Для просмотра общего интерфейса на **изолированных fixtures**, без настоящего
API и без ключа:

```sh
pnpm --dir chatgpt preview
```

Открыть `http://127.0.0.1:8791`. Это локальный тестовый MCP Apps контейнер,
не опубликованный плагин и не доказательство реального ChatGPT smoke.

Тесты пакета проверяют инструменты, маршруты, валидацию, отказ другому
посетителю, ошибки и собранный Worker в workerd. Backend проверяет ключи,
границы аккаунтов, прибавление, повтор и конкурентные изменения в локальной D1.
Frontend проверяет адаптер и существующие пользовательские сценарии.

Локальная проверка 2026-10-01: `pnpm check` и `pnpm boundaries:check` прошли;
93 frontend-теста, 139 backend-тестов и 15 тестов плагина. Frozen install из
корня прошёл. В браузерном fixture-контейнере проверены ввод результата,
создание цели, сохранение настроек, восстановление с сохранённым результатом,
мобильная навигация, светлая/тёмная темы и месяц из позднего результата открытия.
Из iframe не было внешних HTTP-запросов. Новая версия ещё не опубликована;
реальная проверка в ChatGPT выполняется после переключения.

## Сборка и публикация

`pnpm chatgpt:build` собирает общий frontend, встраивает его в Worker и выдаёт:

- `dist/server/index.js` — Sites Worker;
- `dist/.openai/hosting.json` — конфигурация существующего Sites проекта;
- `dist/ui.html` — тот же самодостаточный UI для локальной проверки.

Канонические исходники находятся в общем workspace. Для сборки из исходников
Sites нужен весь workspace, включая frontend и корневой lockfile; отдельного
копирования подпакета, как в прототипе, недостаточно. Для публикации готового
артефакта сохранить в архиве пути `dist/server/index.js` и
`dist/.openai/hosting.json`. Sites не использует D1 или R2.

Публикация API, remote-миграция и публикация Sites требуют отдельного
разрешения. Порядок: миграции `0005` и `0006`, API/веб, создание и настройка ключа,
новый Sites Worker, обновление плагина, реальный smoke в обычном ChatGPT.
Старый прототип остаётся работающим до этого переключения.

Документация протокола: [UI плагина](https://developers.openai.com/plugins/build/chatgpt-ui)
и [MCP Apps](https://github.com/modelcontextprotocol/ext-apps).
Результаты первоначальной проверки: [архив эксперимента](../docs/sites-mcp-test.md).
