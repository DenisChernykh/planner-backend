# Ритм — цели, привычки и результаты

Ритм помогает составить план, регулярно отмечать результаты и видеть свой прогресс. Это полноценное веб-приложение с интерфейсом на React, серверной частью, базой данных, Telegram-ботом и подключением к ChatGPT.

[Открыть приложение](https://app.getplanner.workers.dev/)

Например, можно запланировать три тренировки в неделю, ежедневно записывать количество прочитанных страниц и отмечать время отхода ко сну. Ритм хранит результаты, показывает статистику и напоминает о записях в Telegram.

## Что можно делать

- **Вести планы по месяцам:** создавать цели, задавать частоту выполнения и переносить цели в следующий месяц.
- **Выбирать подходящий способ учёта:** отметка «сделано», число с единицей измерения, оценка по шкале или время.
- **Записывать результаты и заметки:** открывать нужный день, исправлять значение и искать записи в истории.
- **Смотреть прогресс:** графики, выполнение целей за неделю и месяц, серии и сравнение сопоставимых периодов.
- **Получать напоминания в Telegram:** настраивать время, дни, часовой пояс и тихие часы; записывать результаты через бота.
- **Получать сводки:** выбирать цели для отчётов по средам и воскресеньям и настраивать время отправки.
- **Работать через ChatGPT:** читать план, добавлять цели, записывать результаты и открывать тот же интерфейс приложения внутри ChatGPT.

## Что я разработал

- **Интерфейс приложения:** таблицу месячного плана, формы целей, ввод результатов, экран прогресса, поиск, корзину и настройки напоминаний.
- **Серверную часть и базу:** хранение планов и истории, правила четырёх типов учёта, перенос целей между месяцами, авторизацию через Telegram и разделение данных аккаунтов.
- **Расчёт прогресса:** учёт частоты целей, границ недель и месяцев, часового пояса и даты начала наблюдений. Отсутствующая запись остаётся отсутствием данных, а введённый ноль участвует в расчётах.
- **Telegram-бота:** напоминания, ввод результатов, вечерний сбор записей и регулярные сводки.
- **Подключение к ChatGPT:** инструменты чтения и изменения плана, отдельный отзывной ключ доступа и общий с веб-версией интерфейс.
- **Защиту совместного редактирования:** изменения с сайта, из Telegram и ChatGPT проверяют версию записи, чтобы устаревший запрос не затёр новый результат. Повтор команды «добавить ещё 200 мл» с тем же идентификатором не увеличивает значение второй раз.

## Как устроено приложение

React-интерфейс обращается к HTTP API. Сервер проверяет доступ и правила учёта, затем сохраняет данные в D1. Telegram и ChatGPT работают с теми же планами и результатами.

Напоминания выполняет фоновый планировщик: он определяет, кому и когда отправить сообщение, учитывает настройки пользователя и сохраняет результат отправки. Сайт и API размещены в одном Cloudflare Worker.

## Технологии и их задачи

| Технология                        | Для чего используется                                              |
| --------------------------------- | ------------------------------------------------------------------ |
| **React, TypeScript, Vite**       | Интерфейс, интерактивные формы, таблица плана и сборка приложения. |
| **TanStack Query и React Router** | Загрузка и обновление данных, переходы между экранами.             |

| **Cloudflare Workers**            | Размещение сайта и выполнение серверной логики.                    |
| **D1 и Drizzle ORM**              | Хранение аккаунтов, целей, результатов и истории доставки.         |
| **Durable Objects и Alarms**      | Выполнение фонового расписания напоминаний и отчётов.              |
| **grammY и Telegram Bot API**     | Команды бота, напоминания и запись результатов из Telegram.        |
| **MCP и MCP Apps**                | Инструменты и встроенный интерфейс Ритма в ChatGPT.                |
| **Vitest**                        | Проверки расчётов, API, интерфейса и интеграционных сценариев.     |

## Локальная разработка

Node.js 24, pnpm 11.15.1. Установка и команды выполняются из корня репозитория. Настройки окружения описаны в [README серверной части](backend/README.md).

```sh
pnpm install
pnpm db:migrate:local
pnpm dev
```

```sh
pnpm check
```

`check` проверяет контракт API, форматирование, границы модулей, типы, тесты и сборку всех частей. Публикация приложения выполняется отдельно.
