# Ритм — цели, привычки и результаты

Приложение для планирования целей, формирования привычек и учёта результатов. Объединяет веб-интерфейс, Telegram-напоминания и взаимодействие с ChatGPT.

## Возможности

- Планы по месяцам, цели, фактические результаты и работа с историей.
- Telegram-авторизация, расписания и напоминания.
- React SPA, Hono API, D1 и MCP-интеграция в одном workspace.

## Инженерные акценты

- Самостоятельная fullstack-разработка продукта от модели данных до пользовательского сценария.
- Фоновые задачи с сохраняемым состоянием, восстановлением и повторной обработкой.
- Контракт API, модульные границы и автоматизированные проверки frontend/backend.

## Стек

React, TypeScript, TanStack Query, React Router, Tailwind CSS, Vite, Vitest, Hono, Drizzle, grammY.
