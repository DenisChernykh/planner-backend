Сравнение с прежними экспортами использовалось только для ответа на вопрос об их
актуальности: 53 из 54 совпали; в недельном кадре отличалась позиция счётчика целей.

как источник дизайна. Кадр №27 — набор примеров месячного сравнения, разных правил,
неподготовленного соседнего плана и серий; эти случаи реализованы в обычных экранах.
Названия «Тренировки», «Чтение» и другие не являются условиями в коде.
