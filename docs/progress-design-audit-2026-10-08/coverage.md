# Покрытие исходного макета pen.dev

Каталог содержит 53 редактируемых экрана/таблицы состояний и карту. Компоненты
`kynaE` проверены дополнительно: всего 55 кадров прочитаны через MCP.
Источник — [Planner.pen](../../frontend/docs/design/Planner.pen); PNG макетов
не входят в репозиторий. Ниже только снимки работающего приложения на локальных
вымышленных данных. Таблицы состояний сопоставлены с отдельными работающими
состояниями; карта не является продуктовым маршрутом.

[Визуальный отчёт и отличия](../../design-qa.md), [слои Pen](./evidence/pen-inspection.json),
[точные размеры/состояния 94 рендеров](./evidence/design-captures.json).
Ширины приложения: 1440, 390 и 320 CSS px, deviceScaleFactor=1.
Реальное сообщение среды и обе кнопки подтверждены владельцем — [E02](checks.md#e02).
Воскресный и остальные визуальные варианты выше остаются локальными доказательствами.
