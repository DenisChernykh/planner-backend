# Явный остаток после сверки

На ревизии `2e5598d` полная реализация по ТЗ/макетам **не принята**.
У каждого пункта ниже есть связанные строки [матрицы](requirements.md) и условия закрытия.
Эта сессия проверила и зафиксировала остаток; код приложения не исправлялся.

16 подтверждённых исправлений/дополнений, одно противоречие ТЗ ↔ дизайн и 14 групп
недостающих проверок. V — это недостаток доказательств, не автоматически ошибка кода.
Пункты пересекаются по компонентам; их нельзя считать 31 независимой функцией или складывать в процент готовности.

## Условие окончательной приёмки

Для F-пункта: правка + положительный сценарий на тех же данных/размерах + обновлённое доказательство.
Для V-пункта: выполненная проверка с точным expected/actual; чтение кода не заменяет её.
Для Q01: явно согласованное изменение источников/реализации. Затем сверить все строки
матрицы и 18 составных критериев, выполнить root `pnpm check` и `pnpm boundaries:check`,
записать ограничения внешней проверки. Только после этого формулировка «всё готово»
может относиться ко всему согласованному объёму.

Не входят в остаток новые продуктовые функции, исключённые §10: AI, произвольные дни,
экспорт/изображения, достижения, многомесячные отчёты и новые ChatGPT-инструменты.
Деплой/remote migrations/Telegram mutation этой документационной приёмкой не разрешались.
Историческую публикацию `a687a2c` нельзя считать доказательством закрытия F/V/Q.
