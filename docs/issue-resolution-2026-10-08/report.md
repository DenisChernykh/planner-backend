## Регрессионные проверки

Корневой `pnpm check` прошёл: frontend — 127 тестов, backend — 204,
ChatGPT — 16; дополнительно три Node fixture-теста архитектурного gate.
Проверены OpenAPI и генерация клиента, типизация, формат, архитектура,
SPA/ChatGPT сборки, Worker dry-run и локальный smoke монолита.
Отдельный `pnpm boundaries:check` также прошёл.

`backend/test/issue-resolution.spec.ts` воспроизводит 07:00 → Telegram 07:40 →
устаревшее сохранение заметки/удаление. Оба запроса возвращают 409, запись
Telegram сохраняется, явное объединение сохраняет актуальное время и черновик
заметки. Тесты также проверяют конкурирующее создание и повтор после удаления.

Управляемое чередование чтения общих настроек и изменения времени/дней цели
проверяет повтор расчёта. Устаревшее сохранение правила и продвижение Cron
не меняют расписание после смены timezone.

В каждой таблице истории создано по 3 600 свежих строк. `EXPLAIN QUERY PLAN`
показывает retention-индекс, запрос просроченной партии читает менее 10 строк.
Для `reminder_jobs` индекс выбирается без подсказки. Для команд Planning
частичный индекс закреплён в самом запросе: SQLite без статистики иначе может
выбрать индекс `goal_id`. Квитанции с жизненным циклом цели остаются в базе.

Тесты сессии различают 401 и сетевую ошибку, проверяют отмену позднего ответа,
очистку личных данных и смену пользователя. Тесты черновика проверяют обновление
плана, полночь, повтор с исходной ревизией и точное сохранение заметки.

## Браузер и доступность

Chrome, Playwright, axe-core 4.10.3. Viewport 1440×1000/1024, 390×844 и 320×844.
[Основные сценарии](browser-results.json), [обновление и цветовые пары](refresh-contrast-results.json)
и [форма, размеры текста и мобильное сохранение](final-ui-results.json) записаны
отдельно. Физический телефон не использовался.

Проверены сохранение всех четырёх типов на мобильном экране, Enter для сохранения,
Escape для закрытия панели, Cmd/Ctrl+K и открытие результата поиска. В сценарии
возврата во вкладку явно отправлено событие `visibilitychange` браузера; для
полуночи ответ API содержит следующий серверный день. Несохранённые значение,
заметка, дата и ревизия сохраняются. Реального ожидания полуночи не было.

[Дополнительная проверка критериев](final-acceptance.json) включает пустой и
заполненный план, единственный `main` после перехода в итоги и подключения,
мобильное редактирование цели с клавиатуры, отказ API при сохранении,
перемещении в корзину и отмене перемещения. Ошибки сохраняют введённые данные,
повтор работает; результат изменения перечитан после обновления страницы.

Axe не находит нарушений в проверенных состояниях плана и формы шкалы.
Это автоматическая проверка этих экранов, а не утверждение полного соответствия
WCAG. Измеренные пары светлой темы:

возвратили AppleEvent timeout `-1712`. Полученного вывода диктора нет; этот этап
не засчитан. Для закрытия #28 остаётся пройти чтение дня → изменение → сохранение
с настоящим экранным диктором и указать диктор/браузер.
